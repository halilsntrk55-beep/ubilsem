# UBİLSEM

Öğretmenler için ders programı, yıllık plan ve yoklama takip uygulaması.

Tek dosyalı uygulama: `index.html`. Vercel üzerinde Framework Preset: Other seçilir; build komutu ve bağımlılık gerekmez. Firebase Authentication ve Realtime Database bağlantısı için internet gerekir.

Kişisel bilgiler, sınıf listeleri, ders planları ve yoklamalar kaynak kodda bulunmaz; yalnızca yetkili hesaba açık veritabanından yüklenir. Yoklamalar sınıf ve tarih bazında tutulur. Kaydedilmemiş günler devamsızlık sayılmaz.
